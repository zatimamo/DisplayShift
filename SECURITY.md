# Security

Please report security vulnerabilities privately. Do not post credentials or potentially exploitable details in public issues.

Use GitHub private vulnerability reporting if enabled for this repository. Include the DisplayShift version, Windows version and safe reproduction steps.

Only download binaries from this repository's official GitHub Releases. Verify checksums against SHA256SUMS.txt.

The binaries do not carry a trusted Authenticode signature. SHA-256 matching confirms file integrity relative to the published checksums, not the publisher's identity.

DisplayShift's application source is proprietary; third-party library rights and licenses remain applicable.
