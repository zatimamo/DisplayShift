# DisplayShift changelog

## v1.0.2 · Official current release
- Setup chooses English on the first launch after installation or upgrade.
- Later language choices persist; portable installations keep saved language settings.
- Previously named inputs, DDC mappings and other preferences remain unchanged.

## v1.0.1
- Fixed the saved-Arabic startup exception involving early Qt layout events.
- Isolated launch tests passed for all five supported languages.

## v1.0.0 · Official V1
- Initial public version, with DDC/CI input controls, live/interactive preview, Page Up shortcut, Gaming Mode and multilingual UI.

Earlier internal engineering versions are not included in this official release history.
