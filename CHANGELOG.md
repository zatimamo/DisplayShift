# Changelog

Updates to official DisplayShift releases.

## v1.0.2

**Language and installation improvements**

- The installer selects English on the first launch after installation or upgrade.
- Language changes made afterward are saved.
- Portable users keep their previously saved language setting.
- Existing display names, input mappings, and other preferences are preserved.

## v1.0.1

**Startup reliability**

- Fixed a startup error that could occur when Arabic was the saved interface language.
- Improved initialization of the interface and Gaming Mode.
- Verified startup in all five supported languages.

## v1.0.0

**First official release**

Introduced DDC/CI monitor input controls, Page Up switching, second-desktop previews, Gaming Mode, and multilingual support.

Earlier internal development builds are not included in this public changelog.
