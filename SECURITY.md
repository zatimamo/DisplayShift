# Security information

## Reporting a vulnerability

Please report potential security issues privately. Do not share credentials, sensitive logs, or details that could put other users at risk in public issues.

Use GitHub's private vulnerability reporting if it is enabled for this repository. Include the DisplayShift version, Windows version, and steps to reproduce the issue without exposing personal information.

## Download safety

Get DisplayShift only from the [official Releases page](https://github.com/zatimamo/DisplayShift/releases), and use the published [SHA-256 checksums](SHA256SUMS.txt) to verify downloaded files.

DisplayShift is not signed with a trusted Authenticode certificate. Checksums confirm that files match the published release, but do not independently verify the publisher's identity.
